# Finding Funding

Resources for a sustainable funding strategy for independent media and media in exile (EN / FR / ES).
Thomson Media · AGILE programme. Developed by Versátiles | hi@weareversatile.org

- `index.html`: language chooser
- `Funding_Map_2026.xlsx`: funding map (funds, fellowships, regional programmes, resources)
- `en/`, `fr/`, `es/`: resource page, PDF guide (EN, FR) and the interactive diagnostic and project design toolkit
- The toolkit works offline: answers are stored only in the user's browser.

Content prepared, selected and organised based on our own experience mentoring media outlets and journalists. Layout and translation done with the help of AI.
